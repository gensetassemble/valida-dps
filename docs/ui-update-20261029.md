# Pembaruan UI dan interaksi — 29 Oktober 2026

- Tanggal akhir merah bila kurang dari hari ini WITA; kuning bila tersisa 0–90 hari. Tanggal terbit/kalibrasi tidak diberi alarm hanya karena berada di masa lalu. Label dan tooltip melengkapi warna.
- Drag kartu pipeline membuka gate tujuan; kartu berpindah setelah validasi server berhasil. Target yang melewati urutan ditolak. Tombol Status dan aksi tahap menyediakan jalur keyboard/ponsel.
- Gate Hubungi PIC menyiapkan compose Outlook Microsoft 365 berisi PIC utama terverifikasi, subjek, dan teks penawaran yang dapat disunting. Membuka compose tidak mencatat pengiriman atau memindahkan kartu. Pengguna tetap mengirim di Outlook dan mengonfirmasi aktivitas. Gate penawaran/PO memerlukan PDF privat.
- Logout memakai form POST native ke `/auth/logout`, menghapus cookie sesi beserta chunk-nya, lalu mengirim redirect 303 ke `/login`. Navigasi penuh menghindari router/modal lama yang masih menampilkan halaman terproteksi. Proxy tidak merefresh sesi pada endpoint logout; pembersihan lokal tetap berjalan ketika layanan Auth gagal. Logout terlihat di header dan mengakhiri sesi perangkat ini; profil, peran, dan RLS tetap diperiksa pada permintaan berikutnya.
- Sepuluh referensi PIC portofolio memakai roster bisnis tujuh AM. Kode SCE dinormalisasi ke SERCO sesuai koreksi pengguna, dengan alias SCE yang tetap terlacak. Penugasan bisnis tidak membuat akun login atau memperluas akses. Nama riil disimpan di database privat; kode dan migrasi tidak berisi nama/identitas sumber.
- Daftar utama mengambil 40 baris awal, menambah per 40 saat scroll, menggabungkan label relasi, dan mengabaikan respons filter lama. Filter/sort memulai daftar baru; data yang sudah tampil tetap ada saat pemuatan berikutnya gagal dan dapat dicoba ulang. Tidak ada tombol panah pagination.
- Matriks kompetensi ditampilkan sebagai daftar yang dapat discroll. Staging, ringkasan dashboard dan kolom kanban tumbuh kumulatif melalui penanda scroll, sambil mempertahankan filter URL. Batas pengambilan aman tetap berlaku; gunakan filter untuk mempersempit koleksi besar.
- Konteks Auth tetap diperiksa segar, sementara profil/peran/cabang dibaca paralel; client Supabase dideduplikasi per request. Formulir baru dimuat ketika dibuka. Kuantitas dan kartu kanban berasal dari satu scan terotorisasi, menggantikan tujuh query utama sebelumnya. Data privat tidak dicache lintas pengguna.
- Slot `default.tsx` pada dashboard mempertahankan route auth/root dan direct-link popup sesuai route matching ketat Next.js yang terpasang.

## Verifikasi

68 tes unit, lint, TypeScript, dan build production berhasil. Suite SQL pencarian/roster/board menguji nilai uang tepat, pencarian semua token, contoh, ukuran slice, dan pembatasan cabang; fixture dibuat dalam transaksi rollback sehingga tes tidak bergantung pada akun development privat.

Pengujian browser production lokal membuktikan drag membuka gate, checkbox konfirmasi diperlukan, gate yang lengkap memindahkan kartu, dan penawaran tanpa PDF ditolak. Compose membuka endpoint Outlook dengan parameter yang sesuai, lalu meminta login Microsoft pada sesi pengujian; tampilan draft setelah login Microsoft belum diverifikasi. Tidak ada email yang dikirim.

Scroll alat menambah 40 menjadi 80 baris; pencarian meresetnya menjadi dua hasil yang sesuai. Logout kembali ke login dan halaman data terlindungi. Data QA sementara dibersihkan setelah uji; database kembali ke 173 alat, 181 peristiwa, 54 lisensi, 10 sertifikat klien contoh, dan nol log komunikasi QA.

Pemeriksaan tujuh peran mempertahankan seluruh 206 observasi sumber. Audit sumber/build dan riwayat Git tidak menemukan nilai privat pegawai maupun kredensial akun yang diprovisi.
